# 🌍 Travel & Tourism Website

## 📌 Project Overview

This is a fully responsive **Travel and Tourism Website** built using **HTML, CSS, and JavaScript**. The website provides users with an interactive platform to explore travel destinations, view tour details, and simulate a complete booking experience.

The project includes multiple pages such as Home, About, Contact, Gallery, Destinations, Booking, Cart, Login, and Signup, making it a complete front-end travel website system.

---

## 🚀 Features

### 🏠 Home Page
- Attractive landing page with hero section
- Featured destinations
- Navigation to all main pages

---

### 📞 Contact Page
- Contact form for user inquiries
- Contact details section
- Simple and responsive layout

---

### 🖼️ Gallery Page
- Image gallery showcasing travel destinations
- Responsive grid layout

---

### 🌍 Destinations Page
- List of available travel destinations
- Short descriptions for each destination

---

### 🧭 Tour Details Page
- Detailed information about selected tours
- Price, duration, and description
- Booking option

---

### 🛒 Cart Page
- View selected tours/packages
- Remove items from cart
- Clear cart functionality
- Checkout button

---

### 🧾 Booking Page
- Navigation to tour details
- Add to cart button
- Submit booking request

---

### 🔐 Authentication Pages

#### Login Page
- User login form
- Email and password validation

#### Signup Page
- User registration form
- Required field validation
- Navigation between login and signup

---

## 📱 Responsive Design

- Fully responsive layout
- Works on mobile, tablet, and desktop devices
- Mobile-friendly navigation

---
